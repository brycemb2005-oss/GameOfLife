Hello! Welcome to the wonderful world of Conways Game of Life. 
When you run the program it will tell you what inputs it wants 
and will direct you using errors if you enter an invalid input. 
What this code does is it simulates Conways Game of life using a grid of 
"cells" created from information found in the input.txt file or from standard input.
This program also iterates over generations using input from the user.
